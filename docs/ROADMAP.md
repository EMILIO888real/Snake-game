# Roadmap
some of these features may be added in a different order or not at all, but this is the general plan for the future of the project.

## Version 0.30.0
- Upgrade the settings menu.

## Version 0.31.0
- Add automatic report sending using the Gofile API.

## Version 0.32.0
- Add a setting for the simple bot to run multiple snake games simultaneously.

## Version 0.33.0
- Implement resizable window mode.
